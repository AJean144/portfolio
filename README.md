# andelljean.me

Portfolio for Andell Jean-Jacques, Applied AI Engineer. Vite + React, one stylesheet, a lazy-loaded THREE.js fruit in the hero.

```sh
npm install
npm run dev      # local
npm run build    # dist/
```

## Editing

- **Content:** `src/content.js`. It must match the resume in `public/Andell_Jean-Jacques_Resume.pdf`. Update both together.
- **Styles:** `src/index.css`. Palette and fonts live in `:root`.
- **Design rules:** `PRODUCT.md` (product truth) and `DESIGN.md` (visual system).
